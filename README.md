# External Downloads Host

Backend of my [Mihon extensions](https://github.com/yanagiragi/extensions-source/tree/external-downloads/src/zh/externaldownloads)

## Setup

Place your manga folder at `public/assets`

```
└── 📁 public/assets
    ├── 📁 Ordered
    │   ├── 📁 ArtistName
    │   │   ├── 📦 ManagaName.zip
    │   │   └── ...
    │   └── ...
    ├── 📁 UnOrdered
    │   ├── 📦 ManagaName.zip
    │   └── ...
    ├── 📁 Thumbnail
    │   ├── 🖼️ ManagaName.thumb
    │   └── ...
    └── 📜 p_data_19700101.json
```

The above files are generated by [yanagiragi/Ehviewer-metadata-tool](https://github.com/yanagiragi/Ehviewer-metadata-tool) using metadata collected from modified Ehviewer [yanagiragi/Ehviewer_CN_SXJ](https://github.com/yanagiragi/Ehviewer_CN_SXJ).
